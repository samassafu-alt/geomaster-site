# Site public de GeoMaster

Pages publiées par GitHub Pages à partir de la branche `main` :

| Page | Adresse | À quoi elle sert |
|---|---|---|
| Accueil | `/` | Présentation + liens de défi partagés depuis le jeu |
| Confidentialité | `/privacy.html` | **Adresse à coller dans la Google Play Console** |
| Conditions | `/terms.html` | Conditions d'utilisation, 8 langues |
| Crédits photos | `/credits.html` | Auteurs et licences des photos (obligatoire pour CC BY / CC BY-SA) |

Le code du jeu est dans le dépôt privé `geomaster`. Ici, uniquement des pages publiques.
